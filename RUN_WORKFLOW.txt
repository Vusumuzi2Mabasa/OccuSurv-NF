Repeat the same Nextflow command with -resume to use its cache.
Use -profile smoke --outdir results-smoke-new for 40 simulated workers.
Use a fresh output directory per design; published files from older designs
are not automatically removed by Nextflow.

Six processes: SIMULATE -> QC -> LONGITUDINAL_INPUT -> ANALYSE_R ->
CROSSCHECK -> REPORT. R analysis also reads the cleaned baseline records.
Python generates the reference synthetic records and validates input QC.
R computes descriptive statistics, KM, baseline Cox, time-varying Cox,
Aalen-Johansen cumulative incidence, bootstrap intervals and all nine figures.
Python independently checks R outputs and shared bootstrap resamples.
Quarto executes report/OccuSurv.qmd and produces the Word report with native
Word equations and tables. Both scenarios use the 30-event model gate.
